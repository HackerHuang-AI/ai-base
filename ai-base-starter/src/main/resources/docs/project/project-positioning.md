# ai-base 项目定位

## 项目背景

AI 智能能力管理平台需要先统一用户、租户和组织等基础身份上下文，后续 Agent、会话记忆、知识库和用量分析等业务才能明确数据归属与隔离边界。

## 项目定位

`ai-base` 是平台的基础域服务，负责承载身份、租户、组织、菜单和权限等通用管理能力；不承担模型调用、工具执行、记忆或知识检索等 AI 运行时职责。

## 主要功能

- 用户基础档案与 SSO 身份映射；
- 企业租户入驻申请、管理员审核及租户成员管理；
- 组织架构、角色、菜单和权限管理；
- 向下游模块提供可信的 `user_id`、`tenant_id` 等基础身份上下文。

## 主要功能对应技术栈

| 功能 | 关键技术栈 |
| --- | --- |
| 身份接入与用户映射 | 企业 SSO、Dubbo 契约 |
| 租户与权限管理 | MySQL、MyBatis-Plus |
| 身份上下文服务化 | Dubbo Triple、Nacos 服务发现 |
| 请求链路追踪 | Spring MVC Interceptor、MDC、TraceId |
